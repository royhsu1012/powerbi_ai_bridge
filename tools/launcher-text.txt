# =============================================================================
#  啟動檔（🚀啟動PBI終極儀表板.bat）畫面上的所有文字
# =============================================================================
#  為什麼放在這裡：cmd 以「位元組」定位 .bat 檔，.bat 裡只要出現中文，goto 就可能
#  跳到某一行的中間，所以 .bat 只能有 ASCII。中文全部放在這一份，.bat 依代號印出。
#
#  格式：每一行是「代號|要印出的文字」。同一個代號可以有好幾行，照順序印出；
#        只有「代號|」的那一行印出空白行。# 開頭的是註解，不會印出來。
#
#  排版：
#    · 步驟行（STEP1 ~ STEP5）從第 0 欄開始，後面由 .bat 接一個空格和結果（R_ 開頭）
#    · 步驟底下的說明縮排 6 格，條列項目 8 格
#    · 其餘獨立的訊息（RUNNING、PORT_BUSY、START）縮排 2 格
#    · 一行不超過 80 格（中文字一個算兩格）
#
#  修改時請注意：
#    · 存檔保持 UTF-8（不要存成 ANSI / Big5）
#    · 代號要和 .bat 裡的 call :SAY / :SAYN / :ASK 一致。改完跑一次
#      tools\Test-BridgeClient.ps1，它會檢查代號對不對得上、每行有沒有超過 80 格
#    · ASK_ 開頭的是提問行：只能有一行、不能有雙引號。choice 會吃掉行首的半形空白，
#      所以縮排要用全形空白「　」（三個全形空白 = 六格）
#    · STEP 開頭的只能有一行、不能有雙引號、開頭不能是空白（set /p 會吃掉）
# =============================================================================
